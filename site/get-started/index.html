Local Lab prototype

Start with a small Python experiment.

The source includes an early local browser interface. Your computer runs the container; the public website does not receive your code or files through this setup.

The setup guide currently uses Terminal to start the prototype. A packaged desktop installer and automatic website pairing are still in development.

Download project source ↗Read local Lab setup instructions ↗

What you choose locally

  1. FolderOptionally select one folder; the prototype mounts it read-only for the run.
  2. ComputeChoose one of the available CPU and memory limits before running.
  3. RunReview and run one Python code cell in a container without network access.
  4. NotebookOpen a standard .ipynb file with exactly one code cell, edit that cell and download a copy. Previous outputs are cleared; files are not saved automatically.

Multi-cell notebook editing, persistent kernels, GPU access, extra languages and full MainAIger setup are planned. The prototype does not configure those features yet.
