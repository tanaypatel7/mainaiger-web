What is shared?

You choose the public fields

A space name and description, with optional broad region, device categories, counts, compute totals and API categories. Location is manually selected. This page does not scan your network or request GPS access.

Files and activity stay elsewhere

The directory does not collect files, commands, notebook contents or activity logs. Each installation must enforce its own permissions. API keys, connection addresses and folder paths do not belong in a listing or request.

Account metadata is central

MainAIger’s operator can administer website account records, saved listing drafts and access requests. Requests are visible in the application only to the sender and space owner. Hosting and authentication services may retain connection metadata.

Unpublishing removes a listing from this directory. It cannot recall copies others already saved. Deleting a space removes its directory listing and associated requests; it does not revoke permissions already configured on an independent server.
