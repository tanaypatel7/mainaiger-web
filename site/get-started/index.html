Local Lab · Mac developer preview

Download, open, and let the Lab guide the rest.

The app runs only on your Mac and talks to your browser on this computer. Your code and files never go to the website. No account is needed for local use.

This preview is built by the project's public build pipeline and signed with an ad-hoc signature, not an Apple Developer ID, so macOS asks once before the first launch (step 2). Apple silicon and Intel builds are provided.

What happens on your Mac

  1. InstallOpen the downloaded disk image and drag MainAIger Lab to Applications.
  2. Allow onceOpen the app. macOS says it cannot verify it; choose System Settings → Privacy & Security → Open Anyway. This is expected for the unsigned preview.
  3. UnlockThe launcher opens the Lab in your browser. Select Open owner key, copy the key from TextEdit into the page. The key never leaves your Mac.
  4. Setup MainbookRun the device check. If Docker Desktop is missing, the Lab downloads and verifies Docker's installer and opens it; you finish Docker's own prompts. Then download the Python image.
  5. RunChoose an optional read-only folder and CPU/memory limits, start a session, and run Python cells that share variables, with no network inside the container.

Status: the app build, tests and packaging run on GitHub's macOS machines. Installing Docker through the Mainbook and running sessions on a real Mac are still being verified. Multi-cell notebooks, a writable workspace, package environments, Podman as an alternative runtime, GPU access and other languages are planned.
