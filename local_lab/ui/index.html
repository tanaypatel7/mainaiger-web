SETUP MAINBOOK · THIS DEVICE

Prepare your local Lab

Review each step. This preview does not install Docker or create a workspace automatically.

1. Check this device and Docker Desktop

Checks your Mac, available disk space and the local Docker Desktop engine. Runs on this computer. No changes are made.

Select Check this Mac to begin.

If needed, download Docker Desktop from Docker's official installation guide, install it and start it. Its installer may request system permissions.

Operations
docker context inspect desktop-linux
docker --context desktop-linux info
docker --context desktop-linux image inspect --format '{{.Id}}' python:3.13.18-slim
2. Download the Python environment

Downloads the Python container image to Docker Desktop on this computer. This needs network access and disk space. Code execution remains network-disabled. The image tag is mutable and its digest has not yet been verified.

Operation
docker --context desktop-linux pull --quiet python:3.13.18-slim
Check this Mac first.
3. Select permissions and try Python

Use the session settings below to select an optional read-only folder and CPU and memory limits. This preview does not save a workspace or settings permanently. Run the example in a fresh container after reviewing it.
