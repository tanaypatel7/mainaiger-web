INSTALL · THIS MAC

Get Docker Desktop

Not started

Download and verify Docker's official Mac installer. Then open the installer and follow its native instructions.

Review source, permissions and operations

Run the device check to see the installer source.

Download needs network access and disk space. MainAIger saves the installer in its private setup folder. Verification runs before the installer opens. Docker or macOS may request your decision or authorization.

The installer opens in macOS. You will move Docker to Applications, start it, and review Docker's terms. MainAIger does not accept terms for you.

Run the check first. If Docker is already installed, you can use it.

Need the manual option? Open Docker's installation guide.
