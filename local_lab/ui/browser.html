SCRIPTS

A browser script is a short, fixed list of steps a browser on this Mac follows — open a page, wait, click, type, scroll, read the text, follow links — kept as a JSON file in your Memory folder (browser/scripts). The browser only ever navigates to the sites the script lists; each run is reviewed before it starts and logged; what it reads lands in browser/captures, from where one click turns pages into chat notes for the review loop. Fragile by nature: sites change their pages, log-ins and bot checks break scripts, and some sites' terms restrict automated access. Use the official export where one exists (ChatGPT, Claude); use this for sites without one and for your own tools.

Approve a Memory folder first (Memory page).
